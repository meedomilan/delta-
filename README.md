# Ahmed Retest Entry Trader v2 — 15M Retest

مشروع مستقل للدخول بعد إعادة الاختبار فقط.

## المنطق الجديد
1. يحدد الاتجاه من 1H و4H.
2. يرصد الكسر مباشرة على 15M أثناء تكون الشمعة.
3. لا يدخل وقت الكسر.
4. ينتظر رجوع السعر إلى مستوى الكسر على 15M.
5. يؤكد إعادة الاختبار على شمعة 1M مغلقة.
6. يرفض الدخول إذا أصبح السعر بعيدًا عن مستوى الكسر.
7. يرسل منطقة دخول + SL + TP1/TP2/TP3.

## لماذا هذه النسخة أبكر؟
- لا ننتظر كسر 1H أو 4H.
- 1H/4H يستخدمان كاتجاه فقط.
- الكسر الفعلي على 15M.
- إعادة الاختبار تفحص كل 5 ثوانٍ.
- تأكيد الدخول 1M، لذلك التأخير النظري غالبًا أقل من دقيقة بعد ظهور تأكيد صحيح.

## v3 MTF
- 1H/4H: اتجاه.
- 15M: الكسر.
- 5M: إعادة الاختبار وهيكل الوقف.
- 1M: تأكيد الدخول فقط.
- BUY: الوقف أسفل آخر قاع ضمن آخر 12 شمعة 5M + 0.12 ATR.
- SELL: الوقف أعلى آخر قمة ضمن آخر 12 شمعة 5M + 0.12 ATR.
- لا يتم تقريب الوقف صناعيًا إذا كان القاع/القمة الحقيقي أبعد.
- TP1=1.25R، TP2=2R، TP3=3R افتراضيًا.
